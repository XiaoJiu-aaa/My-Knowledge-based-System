### insert优化
	·批量插入
```sql
insert into tb_name values (x),(xxx)...;
```
	·手动提交事务
```sql
start transaction;
...
commit;
```
	·主键顺序插入
##### 大批量插入数据
```bash
# 启动参数
mysql --local-infile -u root -p
```
```sql
-- 开启开关
set global local_infile = 1;

-- 执行load
load data local infile '文件路径' into table '表名' fields terminated by '间隔符' lines terminated by '\n';
```
