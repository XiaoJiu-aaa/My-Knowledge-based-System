# ==增==
#### 1.给指定字段添加数据
```sql
insert into 表名(字段名1,字段名2...) values(值1,值2...);
```
#### 2.给全部字段添加数据
```sql
insert into 表名 values(v1,v2...);
```
#### 3.批量添加数据
```sql
--指定字段
insert into 表名(z1,z2...) values(v1,v2..),(v1,v2...);
--全部字段批量添加
insert into 表名 values (v1,v2...),(v1,v2...);
```

> [!NOTE] 注意
> 1.插入数据时，指定的字段顺序需要与值的顺序是一一对应的
> 2.字符串和日期类型数据需要用引号包含
> 3.输入的数据大小应该在规定范围内

# ==删==
```sql
delete from 表名 [where 条件];
```
> 不能单独删除某个字段
# ==改==
#### 修改数据
```sql
update 表名 set 字段名1=v1,字段名2=v2... [where 条件];
```
