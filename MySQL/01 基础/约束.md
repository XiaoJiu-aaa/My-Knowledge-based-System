
> [!info] 概述
> 约束是作用于表中字段上的规则，用于限制存储在表中的数据,可以在创建/修改表时添加约束
> 目的是保证数据库中的数据正确、有效性和完整性

#### 分类

| 约束   | 说明                           | 关键字         |
| ---- | ---------------------------- | ----------- |
| 非空约束 | 限制数据非NULL                    | not null    |
| 唯一约束 | 保证字段中的数据唯一                   | unique      |
| 主键约束 | 主键是一行数据的唯一标识，要求非空且唯一         | primary key |
| 默认约束 | 保存数据时，如果未指定该字段的值，则采用默认值      | default     |
| 检查约束 | 保证字段值满足某一个条件                 | check       |
| 外键约束 | 用来让两张表的数据之间建立连接，保证数据的一致性和完整性 | foreign key |
auto_increment:自动增长（插入失败也会自动增长）

## 外键约束
	具有外键的称为子表，关联的表成为父表
```sql
-- 添加外键
create table 表名(
	字段名 数据类型,
	...
	[constraint 外键名称] foreign key(外键字段名) references 主表(主表列名)
);

alter table 表名 add constraint 外键名称 foreign key(外键字段名) references 主表(主表列名)

-- 删除外键
alter table 表名 drop foreign key 外键名称;
```

#### 删除/更新行为

| 行为          | 说明                                                            |
| :---------- | :------------------------------------------------------------ |
| no action   | 当父表中删除/更新对应记录时，首先检查该记录是否右对应外键，如果有则不允许删除/更新                    |
| restrict    | 同上                                                            |
| cascade     | 当父表中删除/更新对应记录时，首先检查该记录是否右对应外键，如果有，则也删除/更新外键在子表中的记录            |
| set null    | 当父表中删除/更新对应记录时，首先检查该记录是否右对应外键，如果有则设置子表中该外键值为null（要求外键允许为null） |
| set default | 父表有变更时，子表将外键列设置成一个默认值（Innodb不支持）                              |
```sql
-- 指定行为
alter table 表名 add constraint 外键名称 foreign key(外键字段名) references 主表(主表列名) on update 行为1 on delete 行为2;
```
