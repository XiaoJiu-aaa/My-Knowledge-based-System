# 逻辑运算与移位指令

## 逻辑运算指令
要求与MOV指令相同（NOT除外）；除NOT外均使OF=CF=0

### AND — 逻辑"与"
- `AND dst, src`
- 应用：指定位清零、清CF/OF
- `AND AL, 0FH` — 高4位清零
- `AND AX, AX` — 自身相与，清CF=OF=0

### OR — 逻辑"或"
- `OR dst, src`
- 应用：指定位置1、清CF/OF
- `OR AL, 88H` — D3和D7置1

### NOT — 逻辑"非"
- `NOT opr` — 按位取反
- 操作数不能是立即数，不影响标志位

### XOR — 逻辑"异或"
- `XOR dst, src`
- `XOR AX, AX` — **自身清零且CF=0**（常用技巧）
- `XOR AL, 0FH` — 高4位保留，低4位求反

### TEST — 测试指令
- `TEST opr1, opr2` — 执行AND但不保存结果，只影响标志
- 常用于**测试指定位的状态**
- `TEST AL, 80H` + `JNZ xxx` — 测试D7是否为1
- `TEST AL, 02H` + `JZ xxx` — 测试bit1是否为0

## 移位指令

### 非循环移位
| 指令 | 操作 | 用途 |
|------|------|------|
| SHL/SAL | 逻辑/算术左移 | 无/有符号×2 |
| SHR | 逻辑右移（高位补0） | 无符号÷2 |
| SAR | 算术右移（高位补符号） | 有符号÷2 |

- 移1位直接给出；移多位次数由**CL**指定
- 左移：CF与最高位不等则OF=1

### 循环移位
| 指令 | 操作 | 带CF？ |
|------|------|--------|
| ROL | 循环左移 | 不带 |
| ROR | 循环右移 | 不带 |
| RCL | 循环左移 | 带CF |
| RCR | 循环右移 | 带CF |

应用：位测试、高低位交换、多字长移位

### 示例
```assembly
; 32位数(DX:AX) × 16
MOV CL, 4
SHL DX, CL       ; 高16位左移4位
MOV BH, AH
SHL AX, CL       ; 低16位左移4位
SHR BH, CL       ; AX高4位移到BH低4位
OR  DL, BH       ; 合并到结果
```
