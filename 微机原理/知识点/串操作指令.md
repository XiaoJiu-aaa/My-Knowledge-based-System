# 串操作指令

> 针对数据块/字符串操作，可实现**存储器到存储器**的数据传送

## 共同特点
- 源串：DS:SI（可段超越）
- 目标串：**ES:DI**（不可段超越！）
- 地址修改方向由 **DF** 决定：DF=0增/DF=1减
- 数据块长度值由 **CX** 指定
- 可加重复前缀自动重复

## 五种串操作指令

| 指令 | 操作 | 影响ZF？ |
|------|------|----------|
| MOVS/MOVSB/MOVSW | (ES:DI) ← (DS:SI) | 否 |
| LODS/LODSB/LODSW | AL/AX ← (DS:SI) | 否 |
| STOS/STOSB/STOSW | (ES:DI) ← AL/AX | 否 |
| CMPS/CMPSB/CMPSW | (DS:SI) - (ES:DI) | 是 |
| SCAS/SCASB/SCASW | AL/AX - (ES:DI) | 是 |

## 重复前缀
| 前缀 | 重复条件 | 适用指令 |
|------|----------|----------|
| REP | CX≠0 | MOVS, LODS, STOS |
| REPE/REPZ | CX≠0 且 ZF=1 | CMPS, SCAS |
| REPNE/REPNZ | CX≠0 且 ZF=0 | CMPS, SCAS |

## 使用示例

### 数据块传送（200字节）
```assembly
LEA SI, MEM1      ; 源地址
LEA DI, MEM2      ; 目标地址
MOV CX, 200       ; 长度
CLD               ; DF=0 增址方向
REP MOVSB         ; 重复传送
HLT
```

### 字符串查找（找'&'）
```assembly
MOV AL, '&'
MOV CX, 100
LEA DI, STRING
CLD
REPNE SCASB       ; 重复扫描直到找到
JZ  FOUND         ; ZF=1 找到了
```

## 对比：MOV vs MOVS
- MOV：不能mem←mem，需用寄存器中转
- MOVS：可直接mem←mem，配合REP实现批量传送，**效率更高**
