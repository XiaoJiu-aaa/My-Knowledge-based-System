# 汇编语言源程序结构

> 完整的.ASM源程序由**数据段、堆栈段、代码段**三个逻辑段组成

## 标准程序框架

```assembly
stack  SEGMENT PARA 'stack'
       DB 100 DUP('stack')
stack  ENDS

data   SEGMENT
       <数据、变量在此定义>
data   ENDS

code   SEGMENT
       ASSUME CS:code, DS:data, ES:data
start: MOV  AX, data
       MOV  DS, AX
       MOV  ES, AX
       <此处加入你自己的程序段>
       MOV  AH, 4CH
       INT  21H           ; 返回DOS
code   ENDS
       END  start
```

## 汇编→执行流程
```
编辑(.ASM) → 汇编(MASM) → 目标(.OBJ) → 连接(LINK) → 执行(.EXE)
```

## 两种语句
| 类型 | 构成 | 对应机器码？ | 执行者 |
|------|------|-------------|--------|
| 指令性语句 | 8086指令助记符 | 有 | CPU |
| 指示性语句 | 伪指令 | 无 | 汇编程序 |

## 语句格式
```
指令性：[标号:] [前缀] 助记符 [操作数], [操作数] [;注释]
指示性：[名字] 伪指令 操作数 [, ...] [;注释]
```

## 标号 vs 名字
| | 出现位置 | 后跟 | 含义 |
|------|----------|------|------|
| 标号 | 指令性语句 | 冒号: | 指令地址 |
| 名字 | 指示性语句 | 空格 | 变量/段/过程名 |

## 操作数
可以是：寄存器、存储单元、常数、表达式
- 常数：二进制(B)、十进制、十六进制(H)、字符串
- 字符串类型：`DB`(字节)、`DW`(字)、`DD`(双字)

## 表达式运算符
| 类型 | 运算符 | 用途 |
|------|--------|------|
| 算术 | + - * / MOD | 数值计算 |
| 逻辑 | AND OR XOR NOT | 数值运算 |
| 关系 | EQ NE LT GT LE GE | 比较（真=全1，假=全0） |
| 取值 | OFFSET SEG TYPE LENGTH SIZE | 取属性 |
| 属性 | PTR | 指定类型 |

> **OFFSET vs LEA**：OFFSET只能取静态偏移地址，LEA可取动态偏移地址。

## 命名规则
- 1~31字符，由字母/？/@/_开头
- 不能用系统保留字（寄存器名、指令助记符等）
