# 8086 寄存器组

> 8088/8086内部有14个16位寄存器

## 通用寄存器（8个）

### 数据寄存器
| 寄存器            | 含义    | 常用用途          |
| -------------- | ----- | ------------- |
| **AX** (AH+AL) | 累加器   | 乘除运算、I/O、结果存放 |
| **BX** (BH+BL) | 基址寄存器 | 间址、基址寻址       |
| **CX** (CH+CL) | 计数器   | 循环次数、移位位数     |
| **DX** (DH+DL) | 数据寄存器 | I/O端口地址、乘除辅助  |

### 指针/变址寄存器
| 寄存器    | 含义      | 常用用途    |
| ------ | ------- | ------- |
| **SP** | 堆栈指针    | 指向栈顶    |
| **BP** | 基址指针    | 指向堆栈中数据 |
| **SI** | 源变址寄存器  | 串操作源地址  |
| **DI** | 目的变址寄存器 | 串操作目标地址 |

## 段寄存器（4个）
| 寄存器 | 含义 | 默认指向 |
|--------|------|---------|
| **CS** | 代码段 | 程序指令 |
| **DS** | 数据段 | 程序数据 |
| **SS** | 堆栈段 | 堆栈操作 |
| **ES** | 附加段 | 串操作目标 |

## 专用寄存器（2个）
| 寄存器 | 含义 |
|--------|------|
| **IP** | 指令指针（存放下条指令偏移地址） |
| **FLAGS** | [[标志寄存器PSW\|标志寄存器]] |

---

## 寄存器使用约定
- **BX, SI, DI** → 默认段DS；**BP** → 默认段SS
- **SP** 始终指向栈顶，PUSH/POP操作自动修改
- **CX** 是LOOP/REP的默认计数器
- **AL/AX** 是乘除/I/O/串操作的默认累加器
- 段寄存器**不能**直接赋值立即数（需用通用寄存器中转）
