# 子程序与宏

> 一次定义，多次调用 — 代码复用的两种方式

## 子程序（过程）

### 定义方式
```assembly
过程名 PROC [NEAR | FAR]
    PUSH ...       ; 保护现场
    <过程体>
    POP ...        ; 恢复现场
    RET
过程名 ENDP
```

### 调用与返回
```assembly
CALL 过程名        ; 调用
  ...
RET                ; 返回（或 RET n，n为弹出参数字节数）
```

### 现场保护与恢复
```assembly
SUBP PROC
    PUSH AX
    PUSH BX
    PUSH CX        ; 保护现场
    ...            ; 过程体
    POP CX
    POP BX
    POP AX         ; 恢复现场（逆序！）
    RET
SUBP ENDP
```

### 参数传递方式
| 方式 | 方法 | 适用场景 |
|------|------|---------|
| 寄存器 | 将参数放入指定寄存器 | 参数少时 |
| 存储单元 | 将参数放入指定内存单元 | 参数较多 |
| 堆栈 | 调用前PUSH参数，过程中用BP寻址 | 嵌套/递归 |

## 宏指令

### 定义方式
```assembly
宏名 MACRO [形参1, 形参2, ...]
    <宏体>
    ENDM
```

### 宏调用与展开
```assembly
; 定义
DADD MACRO X, Y, Z
    MOV AX, X
    ADD AX, Y
    MOV Z, AX
    ENDM

; 调用
DADD DATA1, DATA2, SUM

; 汇编后展开为:
MOV AX, DATA1
ADD AX, DATA2
MOV SUM, AX
```

## 子程序 vs 宏

| 特性 | 子程序 (PROC) | 宏 (MACRO) |
|------|--------------|------------|
| 处理时机 | CPU运行时执行 | 汇编时展开 |
| 目标代码 | 只存一份，节省内存 | 每次调用展开一份 |
| 执行速度 | 较慢（CALL/RET开销） | 较快（无调用开销） |
| 占用空间 | 节省内存 | 不节省内存 |
| 参数传递 | 运行时传递 | 汇编时文本替换 |
| 适用场景 | 功能模块化，代码较长 | 简短重复代码段 |

> 核心取舍：子程序**省空间费时间**，宏**省时间费空间**。
