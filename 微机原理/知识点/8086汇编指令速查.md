# 8086 汇编指令速查

> 按功能分类的常用指令速查表

## 数据传送类
| 指令 | 格式 | 功能 |
|------|------|------|
| MOV | `MOV dst, src` | dst ← src |
| PUSH | `PUSH src` | 压栈 |
| POP | `POP dst` | 弹出 |
| XCHG | `XCHG opr1, opr2` | 交换 |
| XLAT | `XLAT` | 查表 AL←[BX+AL] |
| LEA | `LEA reg, mem` | 取偏移地址 |
| LDS | `LDS reg, mem32` | 取远指针→DS:reg |
| LES | `LES reg, mem32` | 取远指针→ES:reg |
| CBW | `CBW` | AL→AX符号扩展 |
| CWD | `CWD` | AX→DX:AX符号扩展 |
| IN | `IN acc, port` | 端口→累加器 |
| OUT | `OUT port, acc` | 累加器→端口 |

## 算术运算类
| 指令 | 功能 | 特殊点 |
|------|------|--------|
| ADD | 加法 | 影响所有标志 |
| ADC | 带进位加 | +CF，用于多字节 |
| INC | 加1 | 不影响CF |
| SUB | 减法 | 影响所有标志 |
| SBB | 带借位减 | -CF，用于多字节 |
| DEC | 减1 | 不影响CF |
| NEG | 求补 | 0-opr |
| CMP | 比较 | 不保存结果，只影响标志 |
| MUL | 无符号乘 | AL×src→AX 或 AX×src→DX:AX |
| IMUL | 带符号乘 | 同上 |
| DIV | 无符号除 | AX÷src→AL商AH余 或 DX:AX÷src |
| IDIV | 带符号除 | 同上 |

## 逻辑与移位类
| 指令 | 功能 |
|------|------|
| AND | 逻辑与（清零用） |
| OR | 逻辑或（置1用） |
| XOR | 异或（自身清0用） |
| NOT | 取反 |
| TEST | 测试（与但不保存） |
| SHL/SAL | 逻辑/算术左移（×2） |
| SHR | 逻辑右移 |
| SAR | 算术右移（÷2） |
| ROL/ROR | 不带CF循环 |
| RCL/RCR | 带CF循环 |

## 串操作类
| 指令 | 功能 | 重复前缀 |
|------|------|---------|
| MOVSB/W | 串传送 | REP |
| STOSB/W | 存入串 | REP |
| LODSB/W | 从串取 | (一般不用REP) |
| CMPSB/W | 串比较 | REPE/REPNE |
| SCASB/W | 串扫描 | REPE/REPNE |

## 程序控制类
| 指令 | 功能 |
|------|------|
| JMP | 无条件跳转 |
| JZ/JE | ZF=1跳 |
| JNZ/JNE | ZF=0跳 |
| JC/JB | CF=1跳(低于) |
| JNC/JAE | CF=0跳(高于等于) |
| JS | SF=1跳(负) |
| JNS | SF=0跳(正) |
| JO | OF=1跳(溢出) |
| LOOP | CX-1, CX≠0循环 |
| CALL | 调用子程序 |
| RET | 返回 |
| INT n | 软中断 |

## 处理器控制类
| 指令 | 功能 |
|------|------|
| CLC/STC/CMC | 清/置/求反CF |
| CLD/STD | DF=0增/DF=1减 |
| CLI/STI | 关/开中断 |
| NOP | 空操作 |

## 常用DOS调用 (INT 21H)
| AH | 功能 |
|----|------|
| 01H | 键盘输入字符→AL |
| 02H | 显示DL中字符 |
| 09H | 显示DS:DX指向的'$'结尾串 |
| 0AH | 键盘输入字符串 |
| 4CH | 返回DOS |
