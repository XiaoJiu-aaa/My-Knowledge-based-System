# 标志寄存器 PSW

> Program Status Word，16位，共9个标志位

## 6个状态标志（反映运算结果特征）

| 标志     | 名称   | 置1条件          |
| ------ | ---- | ------------- |
| **CF** | 进位标志 | 最高位产生进位/借位    |
| **PF** | 奇偶标志 | 低8位中"1"的个数为偶数 |
| **AF** | 辅助进位 | D3向D4有进位/借位   |
| **ZF** | 零标志  | 运算结果为0        |
| **SF** | 符号标志 | 结果最高位为1（负）    |
| **OF** | 溢出标志 | 带符号数运算结果超出范围  |

> CF是唯一可用指令直接设置的状态标志（CLC/STC/CMC）

## 3个控制标志（由编程者设定）

| 标志 | 名称 | 作用 |
|------|------|------|
| **DF** | 方向标志 | 1=串操作从高→低地址方向 |
| **IF** | 中断标志 | 1=允许响应可屏蔽中断 |
| **TF** | 陷阱标志 | 1=单步执行（调试用） |

## 相关指令
- 状态标志操作：LAHF, SAHF, PUSHF, POPF
- DF控制：STD（置1）, CLD（置0）
- IF控制：STI（置1）, CLI（置0）
- CF控制：STC（置1）, CLC（置0）, CMC（求反）

## 标志位的判读
在 [[程序控制指令|条件转移指令]] 中，各条件跳转都基于这些标志位的组合判断：

- 无符号比较 → 看 **CF** 和 **ZF**
- 带符号比较 → 看 **SF** 和 **OF**
- 乘除运算后 → 看 **OF** 和 **CF**（判断高半部分是否有效）
