# 处理器控制指令

> 控制CPU工作状态的指令

## 标志位操作
| 指令  | 操作             |
| --- | -------------- |
| CLC | CF ← 0（清进位）    |
| STC | CF ← 1（置进位）    |
| CMC | CF ← CF̄（进位求反） |
| CLD | DF ← 0（置增址方向）  |
| STD | DF ← 1（置减址方向）  |
| CLI | IF ← 0（关中断）    |
| STI | IF ← 1（开中断）    |

## 外部同步
| 指令   | 操作         |
| ---- | ---------- |
| HLT  | 暂停，等待中断或复位 |
| WAIT | 等待TEST信号有效 |
| ESC  | 交权给协处理器    |
| LOCK | 总线锁定前缀     |
| NOP  | 空操作（仅IP+1） |

## 常用场景
- CLC：多字节加法前清CF
- STD/CLD：串操作前设方向
- CLI/STI：关/开中断保护临界区
- NOP：短延时或占位
