# 存储器分段与物理地址

> 8086有20根地址线，寻址1MB空间，但寄存器只有16位 → 分段机制

## 核心公式
$$
\text{物理地址} = \text{段基址} \times 16 + \text{偏移地址}
$$
或写作：`物理地址 = 段基址左移4位 + 偏移地址`

## 四个逻辑段
| 段类型 | 段寄存器 | 用途 |
|--------|---------|------|
| 代码段 | CS | 存放程序指令 |
| 数据段 | DS | 存放数据 |
| 堆栈段 | SS | 堆栈操作 |
| 附加段 | ES | 串操作目标 |

## 段寄存器的默认使用
| 访存操作 | 默认段寄存器 | 可否超越 |
|----------|-------------|---------|
| 取指令 | CS | ❌ 不可超越 |
| 堆栈操作(PUSH/POP) | SS | ❌ 不可超越 |
| 串操作目标 | ES | ❌ 不可超越 |
| BP间址 | SS | 可超越 |
| BX/SI/DI间址 | DS | 可超越 |
| 一般数据存取 | DS | 可超越 |

## 物理地址计算示例

```assembly
; 设 DS=2000H, BX=1000H
MOV AL, [BX]
; 物理地址 = 2000H×16 + 1000H
;          = 20000H + 1000H
;          = 21000H

; 设 DS=6000H, SI=1200H
MOV AX, [SI]
; 物理地址 = 60000H + 1200H = 61200H
```

## 段寄存器的限制
- ❌ 不能将立即数直接送段寄存器（需用通用寄存器中转）
- ❌ CS和IP不能作为MOV的目标操作数

```assembly
; 正确的段寄存器赋值方式
MOV AX, DATA      ; DATA是段名
MOV DS, AX
```

## 段超越前缀
当需要显式指定非默认段寄存器时：
```assembly
MOV AX, ES:[BX]    ; 明确使用ES而非默认的DS
MOV DX, CS:[SI]    ; 明确使用CS
```
