# 常用外设

## 键盘
- 矩阵式按键排列
- 每键对应扫描码
- 通过INT 16H或INT 21H读取

## 鼠标
- 机械式/光电式
- 通过INT 33H驱动

## 显示器
| 模式 | 特点 |
|------|------|
| 文本模式 | 80列×25行，显示ASCII字符 |
| 图形模式 | 像素点阵，控制每个像素颜色 |

- 显示控制通过 [[DOS与BIOS功能调用|INT 10H]]实现

## 打印机
- 针式/喷墨/激光
- 通过INT 17H控制
- 并行接口（Centronics标准）

## 磁盘存储器
| 类型 | 特点 |
|------|------|
| 硬盘 | 大容量，高速 |
| 软盘 | 可移动，已淘汰 |
| 光盘 | CD/DVD，光存储 |

- 通过INT 13H进行磁盘操作

## 多媒体设备
- 声卡（音频采集/播放）
- 视频采集卡
- 多媒体指文字、声音、图形、图像等多种信息载体
