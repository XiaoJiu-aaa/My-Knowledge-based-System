# 计算机的发展与分类

## 计算机发展历程
| 代 | 时期 | 核心元件 | 代表 |
|----|------|---------|------|
| 第一代 | 1946-1956 | 电子管 | ENIAC |
| 第二代 | 1957-1964 | 晶体管 | — |
| 第三代 | 1965-1970 | 中小规模集成电路 | — |
| 第四代 | 1971- | 大规模/超大规模集成电路 | — |

## 按规模分类
| 类型 | 特点 |
|------|------|
| 大型机 | 高性能计算 |
| 小型机 | 中小规模应用 |
| 微型计算机 | 个人/桌面应用，**本课程主角** |
| 单片机 | 一片芯片集成CPU+存储器+I/O |

## 微处理器（CPU）发展
- 1971：Intel 4004（4位，第一片微处理器）
- 1974：8080（8位）
- 1978：8086/8088（16位）← **本课程核心**
- 1985：80386（32位）
- 1993：Pentium
- ...→ Core → 龙芯等国产CPU
