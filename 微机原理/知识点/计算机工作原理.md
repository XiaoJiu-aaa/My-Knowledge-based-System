# 计算机工作原理

## 冯·诺依曼体系结构
现代计算机基于**存储程序**原理：

1. 程序和数据以二进制存放在存储器中
2. 按地址顺序取出指令并执行
3. 由运算器、控制器、存储器、输入设备、输出设备五大部件组成

## 计算机工作过程
```
取指令 → 分析指令 → 执行指令 → 取下一条
  ↑                              ↓
  └──────── 循环往复 ────────────┘
```

- **取指**：根据CS:IP从内存取指令
- **译码**：控制器分析指令操作码
- **执行**：EU完成具体操作
- **IP自动递增**：指向下一条指令

## 微型计算机结构
```
CPU(微处理器) ←→ 存储器(内存) ←→ I/O接口 ←→ 外设
     ↕
  系统总线(地址/数据/控制)
```

- **微处理器（MPU）** = 运算器 + 控制器，是微机核心
- **总线**：地址总线(AB)、数据总线(DB)、控制总线(CB)
