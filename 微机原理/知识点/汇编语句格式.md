# 汇编语句格式

> 汇编语言有两种语句：指令性语句和指示性语句

## 指令性语句
由8086指令助记符构成，CPU执行，生成机器码：

```
[标号:] [前缀] 助记符 [操作数], [操作数] [;注释]
```

例：
```assembly
NEXT: MOV  AX, [SI]     ; 取一个数据
      ADD  AX, BX       ; 累加
      LOOP NEXT         ; 循环
```

## 指示性语句
由伪指令构成，汇编程序执行，**不生成机器码**：

```
[名字] 伪指令 操作数 [, ...] [;注释]
```

例：
```assembly
DATA_B DB 10, 5, 10H    ; 定义字节数据
COUNT  EQU 100           ; 定义符号常量
```

## 区别对照
| | 指令性语句 | 指示性语句 |
|---|----------|----------|
| 构成 | 8086指令 | 伪指令 |
| 符号地址 | 标号（后跟冒号:） | 名字（后跟空格） |
| 机器码 | 生成 | 不生成 |
| 执行者 | CPU | 汇编程序 |

## 各部分说明
- **标号**：指令的符号地址，后跟冒号
- **名字**：变量/段/过程名，后跟空格
- **助记符**：MOV, ADD, DB, SEGMENT等
- **操作数**：0~3个，用逗号分隔
- **注释**：以分号`;`开头，说明语句作用而非操作
