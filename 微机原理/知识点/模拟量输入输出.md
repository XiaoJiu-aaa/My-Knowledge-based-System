# 模拟量输入输出

> 实际世界是模拟量，计算机是数字量 → 需要A/D和D/A转换

## 模拟量I/O通道
```
传感器 → 放大器 → 采样保持 → A/D转换 → 计算机
计算机 → D/A转换 → 执行器
```

## D/A转换器（数模转换）
- 将二进制数字量转换为模拟电压/电流
- 主要指标：**分辨率**（位数）、转换精度、转换速度
- 编程：直接向D/A端口输出数字量即可

## A/D转换器（模数转换）
- 将模拟电压转换为二进制数字量
- 主要指标：**分辨率**（位数）、转换精度、转换时间
- 典型步骤：采样 → 保持 → 量化 → 编码

## 编程举例
```assembly
; D/A输出
MOV DX, DA_PORT    ; D/A端口地址
MOV AL, data       ; 要转换的数字量
OUT DX, AL         ; 输出 → 模拟电压

; A/D采集
MOV DX, AD_PORT    ; A/D端口地址
OUT DX, AL         ; 启动转换
WAIT: IN AL, DX    ; 读状态
      TEST AL, 01H ; 转换完成？
      JZ WAIT
      IN AL, DX    ; 读数据
```
