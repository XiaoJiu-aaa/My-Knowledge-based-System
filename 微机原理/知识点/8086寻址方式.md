# 8086寻址方式

> 寻找操作数地址的方法，8086共8种寻址方式

## 1. 立即寻址
- 操作数（常数）直接由指令给出
- **只能用于源操作数**
- 例：`MOV AX, 1C8FH`

## 2. 直接寻址
- 指令中直接给出操作数的16位偏移地址（有效地址EA）
- 默认段寄存器为DS，可显式指定（段超越前缀）
- 例：`MOV AX, [2A00H]`
- 物理地址 = DS×16 + 偏移地址

## 3. 寄存器寻址
- 操作数放在寄存器中
- **与物理地址无关**
- 源和目的操作数字长必须相同
- 例：`MOV AX, BX`
- ❌ `MOV AX, BL` — 字长不同

## 4. 寄存器间接寻址
- EA放在间址寄存器中：**BX, BP, SI, DI**
- ❌ 不能用DX, AX作间址寄存器
- BX/SI/DI → 默认DS段；BP → 默认SS段
- 例：`MOV AX, [BX]`

## 5. 寄存器相对寻址
- EA = 间址寄存器 + 8/16位位移量
- 常用于存取表格或一维数组
- 例：`MOV AX, [BX+8]` / `MOV CX, TABLE[SI]`

## 6. 基址-变址寻址
- EA = 基址寄存器 + 变址寄存器
- 基址：BX或BP；变址：SI或DI
- **同组寄存器不能同时出现**
- ❌ `[BX][BP]` ❌ `[DI][SI]`
- 例：`MOV AX, [BX][SI]`

## 7. 相对基址-变址寻址
- EA = 基址寄存器 + 变址寄存器 + 位移量
- 可方便访问**二维数组**
- 例：`MOV AX, DATA[SI][BX]`

## 8. 隐含寻址
- 指令隐含操作数地址
- 例：`MUL BL` — 隐含被乘数AL，乘积AX
- 类似指令：DIV, CBW, MOVS等

---

## 总结对比
| 寻址方式  | EA来源          | 用途   |
| ----- | ------------- | ---- |
| 立即    | 指令中           | 常数   |
| 直接    | 指令中偏移量        | 简单变量 |
| 寄存器   | 寄存器           | 最快   |
| 寄存器间接 | [BX/BP/SI/DI] | 地址指针 |
| 寄存器相对 | [BX+disp]等    | 一维数组 |
| 基址变址  | [BX+SI]等      | 表格   |
| 相对基变  | [BX+SI+disp]  | 二维数组 |
