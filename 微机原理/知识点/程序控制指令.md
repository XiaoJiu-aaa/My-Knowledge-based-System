# 程序控制指令

> 控制程序的执行流程

## 1. 转移指令 JMP

### 无条件转移
| 类型 | 格式 | 操作 |
|------|------|------|
| 段内短转移 | `JMP SHORT label` | IP←IP+8位位移量(-128~+127) |
| 段内近转移 | `JMP NEAR PTR label` | IP←IP+16位位移量 |
| 段内间接 | `JMP reg16/mem16` | IP←(reg/mem) |
| 段间直接 | `JMP FAR PTR label` | IP←偏移, CS←段基址 |
| 段间间接 | `JMP DWORD PTR mem32` | IP←[mem], CS←[mem+2] |

> 编程中一般写成 `JMP <标号>`，由汇编程序确定类型。

### 条件转移 Jxx
根据 [[标志寄存器PSW|标志位]] 决定是否转移

**无符号数比较后：**
|  指令  |  条件  |  含义  |
|------|------|------|
| JE/JZ | ZF=1 | 等于/为零 |
| JNE/JNZ | ZF=0 | 不等于/不为零 |
| JA/JNBE | CF=0且ZF=0 | 高于 |
| JAE/JNB | CF=0 | 高于等于 |
| JB/JNAE | CF=1 | 低于 |
| JBE/JNA | CF=1或ZF=1 | 低于等于 |

**带符号数比较后：**
| 指令 | 条件 | 含义 |
|------|------|------|
| JG/JNLE | SF=OF且ZF=0 | 大于 |
| JGE/JNL | SF=OF | 大于等于 |
| JL/JNGE | SF≠OF | 小于 |
| JLE/JNG | SF≠OF或ZF=1 | 小于等于 |

**标志位直接判断：**
| 指令 | 条件 |
|------|------|
| JC | CF=1 |
| JNC | CF=0 |
| JO | OF=1 |
| JNO | OF=0 |
| JS | SF=1 |
| JNS | SF=0 |
| JP/JPE | PF=1 |
| JNP/JPO | PF=0 |

## 2. 循环控制 LOOP
- `LOOP label` — CX←CX-1, 若CX≠0则转移
- `LOOPE/LOOPZ label` — CX-1, CX≠0且ZF=1则循环
- `LOOPNE/LOOPNZ label` — CX-1, CX≠0且ZF=0则循环
- JCXZ — CX=0则转移

## 3. 过程调用 CALL/RET
- `CALL proc` — 调用过程（子程序）
- `RET` — 返回调用点
- CALL/RET必须成对出现
- 嵌套调用通过堆栈保存返回地址

## 4. 中断控制
- `INT n` — 软中断调用（如 INT 21H）
- `INTO` — 溢出中断
- `IRET` — 中断返回
