# 数据传送指令

> 实现 存储器 ↔ 寄存器 ↔ I/O 的数据传送

## 1. 通用数据传送 MOV
格式：`MOV dest, src` ; dest ← src

### 可实现的传送
- `MOV reg, reg` — 寄存器间
- `MOV reg/mem, mem/reg` — 寄存器与存储器
- `MOV reg, data` — 立即数→寄存器
- `MOV mem, data` — 立即数→存储器
- `MOV segreg/mem, mem/segreg` — 段寄存器

### MOV使用规则
- 源/目的操作数**类型要一致**
- ❌ 不允许 mem ← mem
- ❌ 不允许 segreg ← segreg
- ❌ 不允许 segreg ← 立即数
- ❌ IP和CS不能作目标操作数

### 变通方法（用AX作桥梁）
```assembly
; mem ← mem
MOV AX, MEM1
MOV MEM2, AX

; segreg ← segreg
MOV AX, DS
MOV ES, AX

; segreg ← 立即数
MOV AX, DATA
MOV DS, AX
```

## 2. 堆栈操作 PUSH/POP
- 堆栈原则：**先进后出，以字为单位**
- `PUSH src` → (SP)←(SP)-2, 数据入栈
- `POP dest` → 数据出栈, (SP)←(SP)+2
- 操作数必须是16位，不能是立即数
- 不能POP到CS
- PUSH从高地址向低地址，POP相反

## 3. 交换指令 XCHG
格式：`XCHG reg, mem/reg`
- 两操作数必须有一个是寄存器
- 不允许使用段寄存器

## 4. 查表指令 XLAT
- `[BX+AL] → AL`
- BX=表首地址，AL=表内位移量

## 5. 字位扩展指令
- **CBW** — AL符号扩展到AX（字节→字）
- **CWD** — AX符号扩展到DX:AX（字→双字）

## 6. I/O指令 IN/OUT
- `IN acc, PORT` / `OUT PORT, acc`
- 直接寻址：8位端口地址（256个）
- 间接寻址：DX指定16位端口地址（64K个）

## 7. 地址传送指令
- **LEA** reg, mem — 取偏移地址（常用）
- **LDS** reg, mem32 — 取远地址指针→DS:reg
- **LES** reg, mem32 — 取远地址指针→ES:reg

## 8. 标志位操作
- LAHF/SAHF — AH↔FLAGS低8位
- PUSHF/POPF — FLAGS↔堆栈
