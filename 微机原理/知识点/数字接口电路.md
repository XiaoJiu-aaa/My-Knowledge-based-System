# 数字接口电路

> CPU与外设之间信息交换的通道，实现信息缓冲、变换、电平转换、联络

## 接口电路的功能
- 信息缓冲（速度匹配）
- 信息变换（串↔并、A/D↔D/A）
- 电平转换
- 联络信号（握手）

## 可编程接口芯片

### 8255 — 并行接口
- 3个8位端口（PA, PB, PC）
- 3种工作方式：基本I/O、选通I/O、双向总线

### 8253 — 定时/计数器
- 3个16位计数器
- 6种工作方式

### 8251 — 串行接口
- 全双工异步/同步收发器
- 用于串行通信

## 串行通信基础
| 概念 | 说明 |
|------|------|
| 波特率 | 每秒传送的二进制位数 |
| 全双工 | 可同时收发 |
| 半双工 | 分时收发 |
| 同步通信 | 以数据块为单位，需时钟同步 |
| 异步通信 | 以字符为单位，起止式 |
