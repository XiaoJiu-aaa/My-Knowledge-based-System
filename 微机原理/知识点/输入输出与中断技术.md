# 输入输出与中断技术

## I/O基本概念
- **I/O端口**：CPU与外设交换信息的通道
- **端口编址**：独立编址（8086），用IN/OUT指令访问
- 寻址方式：直接寻址（8位，256个）、间接寻址（DX，64K个）

## 数据传送方式
| 方式 | 特点 | CPU效率 |
|------|------|---------|
| **无条件传送** | 默认外设就绪，直接读写 | 低 |
| **查询传送** | 反复检测状态位，就绪后传送 | 低 |
| **中断传送** | 外设就绪后主动通知CPU | 中 |
| **DMA** | 外设直接访问内存，无需CPU | 高 |

## 中断系统

### 中断基本概念
- 中断：CPU暂停当前程序，转去执行中断服务程序
- 中断源：引起中断的事件（外设、指令、异常等）
- [[标志寄存器PSW|IF标志]]：控制可屏蔽中断的响应

### 8086中断分类
| 类型 | 来源 | 可屏蔽？ |
|------|------|----------|
| 外部可屏蔽中断 | INTR引脚 | IF=1时响应 |
| 外部非屏蔽中断 | NMI引脚 | 不可屏蔽 |
| 内部中断 | INT n指令、除法错、单步等 | — |

### 中断向量表
- 位于内存**00000H~003FFH**（1KB）
- 每个中断向量占4字节（IP低2字节，CS高2字节）
- 共256个中断向量（类型号0~255）

### 中断响应过程
1. FLAGS压栈
2. IF=TF=0（关中断）
3. CS和IP压栈
4. 从中断向量表取新IP和CS
5. 转去执行中断服务程序
6. IRET返回（弹出IP、CS、FLAGS）

## 8259中断控制器
- 可管理8级中断优先级
- 可级联扩展到64级

## DMA（直接存储器访问）
- DMAC接管总线控制权
- 实现外设↔内存的高速数据传送
- 无需CPU参与
