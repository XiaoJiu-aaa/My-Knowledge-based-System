# 伪指令

> 由**汇编程序**执行的指令，不被汇编成机器码，用于定义变量、分配存储区、定义段等。

## 数据定义伪指令
| 指令 | 含义 | 例 |
|------|------|-----|
| DB | 定义字节 | `DATA_B DB 10, 5, 10H` |
| DW | 定义字 | `DATA_W DW 100H, -4` |
| DD | 定义双字 | `DATA_D DD 0FFFBH` |

- `?` — 预留空间，不存数据
- DUP — 重复定义：`RSV DW 8 DUP(?)` = 预留8个字
- 字符串用DB：`STR DB 'HELLO'`

## 符号定义伪指令
| 指令 | 可重复定义？ |
|------|-------------|
| EQU | ❌ 清除前不能重定义（用PURGE清除） |
| = | ✅ 可随时重定义 |

```assembly
FIVE  EQU 5
COUNT EQU CX
DIST  = BYTE PTR[SI+BP]    ; =可重定义
```

## 段定义伪指令
```assembly
段名 SEGMENT [定位类型] [组合类型] ['类别']
     <语句>
段名 ENDS
```

### 定位类型
| 类型 | 起始边界 |
|------|---------|
| PARA（默认） | 节边界（16的倍数，××××0H） |
| BYTE | 任意字节 |
| WORD | 偶地址 |
| PAGE | 页边界（256的倍数） |

### 组合类型
| 类型 | 连接方式 |
|------|---------|
| NONE | 不组合 |
| PUBLIC | 依次连接 |
| COMMON | 覆盖 |
| STACK | 堆栈段连接 |

## 设定段寄存器 ASSUME
```assembly
ASSUME CS:code, DS:data, ES:data, SS:stack
```
说明逻辑段与段寄存器的对应关系。

## 过程定义
```assembly
过程名 PROC [NEAR/FAR]
      ...
      RET
过程名 ENDP
```
- NEAR（默认）：段内调用
- FAR：段间调用

## 宏命令
```assembly
宏名 MACRO [形参]
     <宏体>
     ENDM
```
- 宏展开在汇编时完成（不省内存）
- 过程调用在运行时完成（省内存但慢）

## ORG — 定位伪指令
`ORG <表达式>` — 规定段内数据/指令的开始偏移地址

## END — 汇编结束
`END [启动标号]` — 汇编到此结束，可选指定程序入口
