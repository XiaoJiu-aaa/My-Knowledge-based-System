# 算术运算指令

> 8086算术运算指令大多影响 [[标志寄存器PSW|状态标志位]]

## 加法指令
| 指令 | 格式 | 操作 |
|------|------|------|
| ADD | `ADD dst, src` | dst ← dst + src |
| ADC | `ADC dst, src` | dst ← dst + src + CF |
| INC | `INC opr` | opr ← opr + 1 |

- ADC用于**多字节/多字加法**，使用前CF需清零
- INC不影响CF，常用于修改地址指针
- INC操作数不能是段寄存器或立即数
- 存储器操作数需用BYTE PTR/WORD PTR指明类型

## 减法指令
| 指令 | 格式 | 操作 |
|------|------|------|
| SUB | `SUB dst, src` | dst ← dst - src |
| SBB | `SBB dst, src` | dst ← dst - src - CF |
| DEC | `DEC opr` | opr ← opr - 1 |
| NEG | `NEG opr` | opr ← 0 - opr (求补) |
| CMP | `CMP opr1, opr2` | opr1 - opr2 (不保存结果) |

### CMP比较规则
- **无符号数**：CF=0 → opr1 > opr2；CF=1 → opr1 < opr2
- **带符号数**：OF和SF共同决定
  - OF=SF → opr1 > opr2
  - OF≠SF → opr1 < opr2

## 乘法指令
| 指令 | 含义 | 操作 |
|------|------|------|
| MUL src | 无符号乘 | AL×src→AX（字节）/ AX×src→DX:AX（字） |
| IMUL src | 带符号乘 | 同上，负数自动求补处理 |

- 隐含寻址：被乘数在AL/AX，结果在AX或DX:AX
- 若结果高半部分=0，则OF=CF=0

## 除法指令
| 指令 | 含义 | 操作 |
|------|------|------|
| DIV src | 无符号除 | AX÷src → AL(商) AH(余) |
| IDIV src | 带符号除 | DX:AX÷src → AX(商) DX(余) |

> **要求被除数是除数的双倍字长！** 除法前需用CBW/CWD扩展。

## BCD码调整指令
共6条，隐含寻址，**紧跟在算术运算指令后使用**：
- DAA/DAS — 压缩BCD加减调整
- AAA/AAS — 非压缩BCD加减调整
- AAM/AAD — 乘除调整
