# 存储系统

## 存储器分类
| 类型 | 特点 |
|------|------|
| **半导体存储器** | 速度快，容量适中（内存） |
| **磁表面存储器** | 容量大，速度慢（硬盘） |
| **光存储器** | 可移动，只读/可写（光盘） |

## 半导体存储器的分类
```
半导体存储器
├── RAM（随机存取，断电丢失）
│   ├── SRAM（静态，快，贵，用作Cache）
│   └── DRAM（动态，需刷新，用作主存）
└── ROM（只读，断电保持）
    ├── ROM（掩模）
    ├── PROM（可编程一次）
    ├── EPROM（紫外线擦除）
    └── EEPROM／Flash（电擦除）
```

## 存储器的主要性能指标
- **容量**：存储单元数 × 数据位数
- **存取速度**：访问时间、存取周期
- **功耗**
- **可靠性**

## 存储器扩展技术

### 位扩展（扩充字长）
- 多片芯片并联地址线和控制线
- 数据线分开，每片负责部分数据位

### 字扩展（扩充容量）
- 用高位地址线经译码器产生片选信号
- 同一时刻只有一片工作

### 字位同时扩展
- 先位扩展成所需字长，再字扩展扩大容量

## 高速缓存 Cache
- 位于CPU与主存之间的**小容量高速存储器**
- 原理：程序的**局部性**（时间局部性 + 空间局部性）
- 命中率：CPU访问Cache命中的概率
- 写策略：写直达（Write Through）、写回（Write Back）

## 存储器的层次结构
```
寄存器 <- CPU内部，最快最小
  ↓
Cache <- SRAM，几十KB~几MB
  ↓
主存 <- DRAM，几百MB~几GB
  ↓
外存 <- 硬盘/SSD，几百GB~几TB
```

> 越上层越快越贵，越下层越慢越便宜。目标是让CPU大多数时间访问最上层。
