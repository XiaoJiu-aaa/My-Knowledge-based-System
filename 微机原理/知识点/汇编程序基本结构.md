# 汇编程序基本结构

> 四种基本程序结构：顺序、分支、循环、子程序

## 1. 顺序结构
直线执行，无分支无循环，最简单。

## 2. 分支结构

### IF...THEN 结构
```assembly
    CMP/TEST <条件>
    Jx   label      ; 条件满足则跳过
    <处理体>
label:
    <后续指令>
```

### IF...THEN...ELSE 结构
```assembly
    CMP/TEST <条件>
    Jx   label1     ; 满足转处理1
    <处理体2>        ; ELSE分支
    JMP  label2
label1:
    <处理体1>        ; THEN分支
label2:
    <后续指令>
```

### CASE（多分支）结构
```assembly
    CMP <条件1>
    Jx  label1
    CMP <条件2>
    Jx  label2
    ...
    JMP common_exit
label1: <处理1> → JMP common_exit
label2: <处理2> → JMP common_exit
common_exit:
```

## 3. 循环结构

### DO...UNTIL（先执行后判断）
```assembly
    <初始化>
loop_body:
    <循环体>
    <修改条件>
    Jx  loop_body    ; 条件满足继续
```

### DO...WHILE（先判断后执行）
```assembly
    <初始化>
    JMP check
loop_body:
    <循环体>
check:
    <测试条件>
    Jx  loop_body
```

### 用LOOP实现计数循环
```assembly
    MOV CX, N        ; 循环次数
next:
    <循环体>
    LOOP next        ; CX-1, CX≠0则循环
```

> **循环嵌套**：内外循环不能交叉，控制条件不能混淆。

## 4. 子程序结构

```assembly
; 主程序
    CALL sub_proc    ; 调用子程序
    ...

; 子程序
sub_proc PROC
    PUSH AX         ; 保护现场
    PUSH BX
    ...
    <子程序功能>
    ...
    POP BX          ; 恢复现场
    POP AX
    RET
sub_proc ENDP
```

### 注意事项
- 进入子程序先**保护现场**（压栈）
- 退出前**恢复现场**（弹栈，顺序相反）
- 参数传递三种方式：寄存器、存储单元、堆栈（用BP寻址）
- 子程序可嵌套调用

## 程序设计五步骤
1. 抽象数学模型，确定算法
2. 画流程图（方框=处理，菱形=判断）
3. 分配内存和寄存器
4. 编写源程序（.ASM）
5. 汇编→连接→运行→调试
