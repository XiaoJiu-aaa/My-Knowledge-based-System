
# IP

#### 查看IP
```bash
hostname
```

> [!NOTE] Title
> IPv4 版本地址格式：a.b.c.d abcd为0~255的数字
> 127.0.0.1 用于指代本机
> 
0.0.0.0 
1.可以用于指代本机
2.可以在端口绑定中用来确定绑定关系
3.在一些IP地址限制中，表示所有IP的意思，如放行规则为0.0.0.0时，表示允许任意IP访问


# 主机名
## Linux查看主机名
```bash
hostname
```
## 修改主机名(需要root)
```bash
hostnamectl set-hostname 新主机名
```
