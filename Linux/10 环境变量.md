> 环境变量是系统在运行过程中记录的一些关键信息，KeyValue型结构

## 查看环境变量
```bash
env
```
## 获取变量的值 $
```bash
# 例
echo $PATH
echo ${PATH}ABC # PATH值后加上ABC
```
## 自行设置环境变量
```bash
# 临时设置
export 变量名=变量值
```

> [!NOTE] 永久生效配置
> 针对当前用户生效：配置在当前用户： ~/bashrc文件中
> 针对所有用户生效：配置在系统的：    /etc/profile文件中
> 并通过语法：”source 配置文件“  ，进行立刻生效
 


> [!NOTE] PATH作用
> 环境变量PATH会记录一组目录，目录之间用：隔开。这里记录的是命令的搜索路径，当执行
> 命令会从记录的目录中挨个搜索要执行的命令并执行
