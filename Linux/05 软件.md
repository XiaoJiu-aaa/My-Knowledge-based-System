## 一、软件安装
|  CentOs   |  Ubuntu   |
| :-------: | :-------: |
| .rpm->yum | .deb->apt |
### CentOS yum 命令
	RPM包软件管理器，用于自动化安装配置Linux软件，并可以解决自动依赖问题
	yum [-y] [install | remove | search] 软件名称
		-y : 自动确认，无需手动确认安装或卸载过程
		install : 安装
		remove : 卸载
		search : 搜索
> 注 :  需要联网且为root权限





### Ubuntu apt命令
```bash
apt [-y] [install | remove | search] 软件名称
```
	




### 二、软件启动命令 systemctl
	systemctl start | stop | status | enable | disable 服务名
		start：启动
		stop：关闭
		status：查看状态
		enable：开启开机自启
		disable：关闭开机自启
> 部分软件没有集成到systemctl中，需要手动添加



### 三、软链接--->快捷方式
	创建软链接 
	ln -s 参数1 参数2
		-s : 创建软链接
		参数1 : 被链接的文件/文件夹(需存在)
		参数2 : 要链接去的目的地
