#### 通用格式

	comand [-options] [parameter]
    	comand:命令本身
		-options:可选命令选项，可控制命令的行为细节
		parameter:可选命令参数，多数用于命令的指向目标

---

###  1-*特殊路径符*

|   .    |   ..    |    ~     |
| :----: | :-----: | :------: |
| 表示当前目录 | 表示上一级目录 | 表示HOME目录 |

### 2-* 通配符 *  *
	* : 匹配任意内容(包含空)
		例子: test*,表示匹配任意以test开头的内容
			*test,表示匹配任意以test结尾的内容
			*test*,表示匹配任何包含test的内容

### 3-* 管道符 *     |
	left | right
		功能：将左边命令的结果作为右边命令的输入
		例：cat test.txt | grep "love" 

### 4-* 重定向符 * >         |          >>
	>:将左侧命令的结果，覆盖写入右侧文件中
	>>:将左侧结果，追加写入到右侧文件中
	例：echo “hello” > test.txt


### 5-*反引号*  `
	被反引号包围的内容被作为命令执行
	例：echo `pwd`

### ls
	ls [-a -l -h] [Linux 路径]
		功能:列出该路径下的文件
		-a:列出全部文件(包括隐藏文件)
		-l:以列表的形式展开
		-h:必须和-l一起使用,以易于阅读的方式,列出文件大小


### cd
	cd [Linux路径]
		功能:更改工作目录,即进入该路径
			不写则进入到用户的HOME目录

### pwd
	pwd 
		功能:查看当前所在的工作目录





## 文件操作命令
### mkdir
	mkdir [-p] Linux路径
		功能:创建文件夹
		参数必填:表示文件夹路径
		-p可选：表示自动创建不存在的父目录,适用于创建连续多层级目录
> 注 : mkdir 应该在HOME目录内执行,否则涉及权限而创建失败

### touch
	touch Linux路径
		功能: 创建文件
> 注 : mkdir创建文件夹，touch创建文件，如touch test.txt

### cat 
	cat Linux路径
		功能: 查看文件内容,全部显示
### more
	more Linux路径
		功能: 查看文件内容,如果内容过多,可以一页页的展示
				空格翻页,Q键退出


### cp
	cp [-r] 参数1 参数2
		功能: 复制文件/文件夹
		-r: 可选, 用于复制文件夹使用, 表示递归
		参数1: Linux路径, 表示被复制的文件和文件夹
		参数2: Linux路径, 表示要复制去的地方
### mv
	mv 参数1 参数2 
		功能: 移动文件/文件夹
		参数1: Linux路径,表示被移动的文件/文件夹
		参数2: Linux路径,表示目的地,如果目标不存在,则进行改名,确保目标存在
> 注 : 可用于文件的重命名

### rm 
	rm [-r -f] 参数1 参数2 ....参数N
		功能: 删除文件/文件夹
		-r : 用于删除文件夹
		-f : 强制删除(不弹出提示确认信息),给root用户使用
		参数N : Linux路径 

## 查找命令

### which
	which 要查找的命令
		功能: 查找命令的程序文件的位置

### find 
	find 起始路径 -name "被查找文件名字"
		功能：按名字查找指定文件
		
	find 起始路径 -size +|-n[kMG]
		功能：按文件大小查找文件
			例：find / -size -10k: 查找小于10KB的文件
				find / -size +100M:查找大于100MB的文件

### grep
	grep [-n] 关键字 文件路径
		功能：从文件中通过关键字过滤文件行
		-n: 可选，表示在结果中显示匹配的行的行号
		关键字：必填，表示过滤的关键字，若带有空格或其他特殊符号，则使用“”将其包裹
		文件路径：必填，表示要过滤内容的文件路径，可作为内容输入端口
### wc 
	wc [-c -m -l -w] 文件路径
		功能: 统计
		-c : 统计bytes数量
		-m : 统计字符数量
		-l : 统计行数
		-w : 统计单词数量
		文件路径 : 被统计的文件, 可作为内容的输入端口
	若不加options,则显示 行数+单词数+字符数



### echo 
	echo 输出的内容
		功能：在命令行内输出内容



### tail
	tail [ -f -num ] Linux路径
		功能: 查看文件尾部的内容，跟踪文件的最新更改
		-f : 表示持续跟踪
		-num : 表示查看尾部多少行,不填默认10行 
	如果想要追踪尾部特定行数，则
			tail
