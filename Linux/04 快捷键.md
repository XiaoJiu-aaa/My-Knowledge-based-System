

|   快捷键   | 功能             | 备注         |
| :-----: | :------------- | :--------- |
| CTRL+C  | 强制停止           | -          |
| CTRL+D  | 退出或登录          | 不能退出vi/vim |
| history | 查看历史输入过的命令     | -          |
|  !命令前缀  | 自动执行上一次匹配前缀的命令 | -          |
| CTRL+R  | 输入内容去匹配历史命令    |            |
#### 光标移动

| 快捷键            | 功能     |
| -------------- | ------ |
| CTRL+A         | 跳到命令开头 |
| CTRL+E         | 跳到命令结尾 |
| CTRL+KEY_LEFT  | 左跳一个单词 |
| CTRL+KEY_RIGHT | 右跳一个单词 |
