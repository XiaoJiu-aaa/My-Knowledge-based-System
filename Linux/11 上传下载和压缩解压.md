#### 压缩或解压

> [!NOTE] Title
> .tar : 简单将文件封装，体积减少得不多
> .gz : 极大减少压缩后的体积

##### 1.tar命令
```bash
tar [-c -v -x -f -z -C] 参数1....参数N
# 压缩：
tar -zcvf test.tar 1.txt 2.txt 3.txt
# 解压
tar -xvf test.tar -C /Desktop
```

| 选项  | 说明                      |
| --- | ----------------------- |
| -c  | 创建压缩文件，用于压缩模式           |
| -v  | 显示压缩、解压过程，用于查看进度条       |
| -x  | 解压模式                    |
| -f  | 要创建/解压的文件，-f 必须放在选项中的最后 |
| -z  | gzip模式，不写则是tarball格式    |
| -C  | 选择解压的目的地，用于解压模式         |
##### 2.zip命令
###### 压缩
```bash
zip [-r] 参数1...参数N
# -r : 如果参数里面含有文件夹时需要使用
```

###### 解压
```bash
unzip [-d] 参数
# -d : 指定要解压去的位置，同tar的-C选项
# 例 : unzip test.zip -d /Desktop
```
