###### ls -l 展示的信息中
	drwxr-xr-x. 3 jzx jzx 18 Aug 11 06:09 Desktop
	 drwxr-xr-x ：表示文件/文件夹的权限控制信息
	 jzx ：表示文件/文件夹所属用户
	 jzx ：表示文件/文件夹所属用户组

### 权限信息
	[- d l] [r -][w -][x -] [r -][w -][x -] [r -][w -][x -]
	
	[文件/文件夹/软链接] [所属用户的 读/写/执行 权] [所属用户组的 读/写/执行 权] [其他用户的 读/写/执行权]
		例：drwxr-xr-x:
			1. d :这是一个文件夹
			2. rwx : 所属用户拥有   r、w、x权
			3. r-x : 所属用户组拥有 r、x权
			4. r-x : 其他用户的拥有 r、x权
	r:可以查看文件内容
		·针对文件夹，可以查看文件夹内容，如ls
	w:可以修改文件
		·针对文件夹，可以在文件夹内创建、修改、改名等操作
	x:可以将文件作为程序执行
		·针对文件夹，可以更改工作目录到此文件夹，即cd

### 修改权限信息
#### chmod
	chmod [-R] 权限 文件/文件夹
		-R:对文件夹内的全部内容应用同样的操作
		示例：chmod u=rwx,g=rx,o=x test.txt

	快捷写法：chmod 751 test.txt
	
权限对应表

|  0  | --- |
| :-: | :-: |
|  1  | --x |
|  2  | -w- |
|  3  | -wx |
|  4  | r-- |
|  5  | r-x |
|  6  | rw- |
|  7  | rwx |

即


|  1  |  x  |
| :-: | :-: |
|  2  |  w  |
|  4  |  r  |


>  注：只有文件、文件夹的所属用户或root用户可以修改


> [!NOTE] 特殊例子
> 执行 
> chmod -R u=r,g=w,o= test 时，test首先被修改为r权限，然后由于没有x权限，无法进入test进行修改，相当于自己打断了自己。
> 规避方法：1.手动进入文件夹里面修改 2.chmod -R u=r,g=w,o= test/\*, \*会将其提前展开(==前提是test原本具有rx权限==)

### 修改文件/文件夹所属用户/用户组

#### chown
	chown [-R] [用户][:][用户组] 文件/文件夹
		-R : 对文件夹内的内容应用相同规则
			例 : chown user2:group2 test.txt
				 chown -R :group3 test
				 chown user3 test.txt
> 注 ： 普通用户无法修改所属为其他用户或组，所以命令只适用于root用户执行
