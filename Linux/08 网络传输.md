# ping 命令
```bash
ping [-c num] ip或主机名
# -c : 检查次数，不使用将无限次数的持续检查
```
# wget 命令
```bash
wget [-b] url
# -b : 后台下载，日志写入到当前工作目录的wget-log文件
# url : 下载链接
```

# curl 命令
#### curl可以发送网络请求，可用于下载文件、获取信息等
```bash
curl [-O] url
# -O : 用于下载文件，当url是下载链接时，可以使用此选项保存文件
# url : 要发起请求的网络地址
```


# 端口

> [!NOTE] 分类
> 1.物理端口：又称接口，是可见的端口，如USB接口，RJ45网口，HDMI端口等
> 2.虚拟端口：指计算机内部的端口，是不可见的，是用来操作系统和外部进行交互使用的
## Linux端口分类

| 总数   | 65535       | 说明                              |
| ---- | ----------- | ------------------------------- |
| 公认端口 | 1~1023      | 系统内置或知名程序使用                     |
| 注册端口 | 1024~49151  | 通常可以随意使用，用于松散的绑定一些程序/服务         |
| 动态端口 | 49152~65535 | 通常不会固定绑定程序,而当程序对外进行网络链接时,用于临时使用 |
|      |             |                                 |
## nmap 命令
> 安装：yum -y install nmap
```bash
nmap 被查看的IP地址
# 用于查看端口被占情况
```
## netstat 命令
> 安装：yum -y install net-tools
```bash
netstat -anp | grep 端口号
# 查看指定端口的占用情况
```
