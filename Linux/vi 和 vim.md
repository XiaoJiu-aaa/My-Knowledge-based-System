> 底层命令模式<->命令模式<->输入模式

#### 命令模式快捷键

| *模式* | *命令* |                      *功能* |
| :--: | :--: | ------------------------: |
| 命令模式 |  i   |      在当前光标位置进入 ==*输入模式*== |
| 命令模式 |  a   | 在当前光标位置*之后* 进入 ==*输入模式*== |
| 命令模式 |  I   |     在当前行的开头，进入 ==*输入模式*== |
| 命令模式 |  A   |     在当前行的结尾，进入 ==*输入模式*== |
| 命令模式 |  o   |    在当前光标的下一行进入 ==*输入模式*== |
| 命令模式 |  0   |    在当前光标的上一行进入 ==*输入模式*== |
| 输入模式 | esc  |   任何情况下esc都能回到 ==*命令模式*== |
